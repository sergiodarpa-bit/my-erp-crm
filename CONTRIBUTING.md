# Contribuire a my-erp-crm

- Le modifiche al marchio e le nostre funzioni vanno nei moduli `addons/my_erp_crm_*`
  o in nuovi moduli: evita di modificare i file originali, così gli aggiornamenti di
  sicurezza (`scripts/aggiorna-da-odoo.sh`) si applicano senza conflitti.
- Ogni modifica passa da una pull request con una descrizione chiara.
- Il codice che aggiungi è distribuito con licenza GNU LGPL v3, come il resto del progetto.
