## Segnalare una vulnerabilità

Non aprire una issue pubblica. Usa la segnalazione privata di GitHub
(scheda **Security** → **Report a vulnerability**) di questo repository.

Le vulnerabilità del codice di base di Odoo Community vengono corrette dal progetto
originale e portate qui con `scripts/aggiorna-da-odoo.sh`.
